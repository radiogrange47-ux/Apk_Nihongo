# Banque Nourriture

Cette banque est activable indépendamment de JLPT5, Mes cours et JLPT4 depuis l’accueil. Elle alimente les mini-jeux Vocabulaire et Verbes : produits bruts, fruits et légumes, plats, condiments, boissons, magasin alimentaire, restaurant et bar.

- `vocabulary.json` : aliments, plats, condiments, boissons et mots utiles pour les achats ou les repas.
- `verbs.json` : cuisiner, préparer, commander, réserver, payer, acheter et actions associées.

Chaque entrée utilise `bank: "FOOD"`. Ajouter les nouvelles questions dans le fichier adapté puis déclarer son chemin dans `questions/manifest.json`.
